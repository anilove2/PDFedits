The editor needs a local server

Browsers refuse to load ES modules from file://, so the page opened from disk cannot start. Nothing is uploaded either way — the server is just how the browser is allowed to read the app's own files.

Easiest: double-click start.cmd in the project folder.

Or run: node scripts/serve.js and open http://127.0.0.1:4321/app/

The landing page still works from disk; only the editor needs http.
